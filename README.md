# GitHub User Info

Скрипт получает публичную информацию о пользователе GitHub по логину и сохраняет её в JSON-файл.  
Опционально может сохранить список публичных репозиториев пользователя.

## Возможности

- Получение данных одного пользователя
- Получение списка публичных репозиториев пользователя
- Сохранение в читаемый JSON с отступами
- Обработка ошибок (нет токена, пользователь не найден, проблемы с API)
- Запуск через командную строку

## Требования

- Python 3.10+
- GitHub Personal Access Token

## Установка

1. Клонируй репозиторий:
git clone <ссылка-на-репозиторий>
cd <папка-проекта>

2. Создай и активируй виртуальное окружение:
python -m venv venv
source venv/bin/activate          # Linux / macOS
venv\Scripts\activate             # Windows

3. Установи зависимости:
pip install PyGithub python-dotenv

4. Создай файл .env в корне проекта:
GITHUB_TOKEN=твой_токен

## Использование

Получить только данные пользователя:
python app.py <github_username>

Получить данные пользователя + список репозиториев:
python app.py <github_username> --repos

Пример:
python app.py octocat
python app.py octocat --repos

После выполнения появятся файлы:
- `octocat.json` — данные пользователя
- `octocat_repos.json` — список репозиториев (если указан флаг --repos)

## Ошибки

Скрипт выдаёт понятные сообщения, если:
- Отсутствует GITHUB_TOKEN
- Пользователь не существует
- Проблемы с авторизацией или rate limit
