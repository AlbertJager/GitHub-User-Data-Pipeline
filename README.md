# GitHub User Info

Скрипт получает публичную информацию о пользователе GitHub по логину и сохраняет её в JSON-файл.

## Возможности
- Получение данных одного пользователя
- Сохранение в читаемый JSON с отступами
- Обработка ошибок (нет токена, пользователь не найден, проблемы с API)
- Запуск через командную строку

## Требования
- Python 3.10+
- GitHub Personal Access Token

## Установка
1. Клонируй репозиторий:
git clone <ссылка-на-репозиторий>
cd <папка-проекта>

2. Создай и активируй виртуальное окружение:
python -m venv venv
source venv/bin/activate          # Linux / macOS
venv\Scripts\activate             # Windows

3. Установи зависимости:
pip install PyGithub python-dotenv

4. Создай файл .env в корне проекта:
GITHUB_TOKEN=твой_токен

## Использование
python main.py <github_username>

Пример:
python main.py octocat

После успешного выполнения рядом со скриптом появится файл octocat.json.

## Ошибки
Скрипт выдаёт понятные сообщения, если:
- Отсутствует GITHUB_TOKEN
- Пользователь не существует
- Проблемы с авторизацией или rate limit
